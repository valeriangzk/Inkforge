INKFORGE Studio 2.4.2 pour Windows

Démarrage
1. Python 3 doit être installé.
2. Double-cliquez sur LANCER_INKFORGE.cmd.

Mises à jour
1. Au démarrage, INKFORGE consulte les versions publiées sur GitHub.
2. Si une version plus récente est proposée, cliquez sur Installer la mise à jour.
3. Après le message de confirmation, fermez la fenêtre noire et relancez LANCER_INKFORGE.cmd.

Pendant la phase expérimentale, les projets et leurs versions enregistrées sont effacés à chaque changement de version du studio.
Les clés API gardées en mémoire doivent être ressaisies après le redémarrage.

Dépôt des mises à jour : https://github.com/valeriangzk/Inkforge/releases
