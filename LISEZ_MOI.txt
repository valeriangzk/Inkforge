INKFORGE Studio 2.7.2 pour Windows

Lancer le studio
Double-clique sur LANCER_INKFORGE.cmd et laisse la fenêtre noire ouverte.
Les images, planches, bibliothèques et versions de projet sont enregistrées dans
le dossier _inkforge_travail, à côté du lanceur. Garde ces fichiers ensemble.
Tu peux aussi exporter un projet JSON avec ses images depuis le studio.
Les clés API restent dans l’onglet ouvert.

Générations en arrière-plan
Ajoute tes clés Agnes dans « Clé API ». K1, K2… identifient les clés de cette session.
Lance les vues souhaitées, puis continue à travailler. Ouvre « Générations IA » en
haut à droite et choisis « Voir le résultat » pour valider une vue ou remplir une case.
Garde l’onglet et la fenêtre noire ouverts jusqu’à la validation. Fermer ou recharger
l’onglet fait perdre la file et les aperçus non validés. Une demande déjà envoyée peut
être facturée. Une nouvelle tentative se lance uniquement sur demande.
Le relais accepte quatre générations simultanées au maximum, une par clé, avec une
limite commune de 20 demandes par minute pour les images 1K. Les limites de ton
forfait continuent à s’appliquer. En cas de quota atteint la file attend.
https://agnes-ai.com/doc/terms-of-service
https://github.com/AgnesAI-Labs/AgnesAI-Models/blob/main/docs/TOKEN_PLAN_FAQ.md

Bibliothèque de décors
Dans « Ajouter un décor », nomme le lieu et décris séparément ce que voit la
caméra de face, de gauche, de droite et dans la direction opposée. Enregistre
la fiche. Choisis Jour ou Nuit puis génère et valide la vue souhaitée.
Modifier son texte et la régénérer conserve les autres images validées.
Pour un ancien projet importé, la description unique apparaît en vue de face.

Tu peux aussi importer un panorama à 360° au format 2:1 ou en créer un avec
Agnes à partir de la fiche complète. Une fois le panorama disponible, le bouton
« Cadrer le panorama » de chaque vue produit un cadrage local sans crédits.
Le bouton « Générer » continue à utiliser la description de cette vue.

Studio 3D
« Aperçu 3D rapide » calcule une silhouette sur une grille de 96 points par axe.
« Générer en qualité finale » utilise 160 points par axe et conserve le modèle
ainsi que ses vues de référence. « Ouvrir le modèle enregistré » relit le fichier.
Le moteur se libère après cinq minutes d’inactivité. Pour comparer les temps
sur ton PC, génère deux modèles à partir d’images différentes. Après calcul,
le Studio indique la durée, si le moteur était chargé et le pic mémoire PyTorch.
Une image déjà traitée dans la même qualité peut être relue depuis le cache.

Premier passage depuis la 2.4.2
Le bouton de la 2.4.2 sait copier le programme. Pour sauvegarder aussi tes projets
AVANT de changer le programme, ferme la fenêtre noire et lance l’assistant
MISE_A_JOUR_INKFORGE.cmd. Choisis ton LANCER_INKFORGE.cmd, ouvre le même profil
de navigateur que d’habitude et clique sur « Installer la mise à jour ».
Si la 2.4.2 a signalé une erreur d’enregistrement et que le projet est encore
ouvert, utilise d’abord « Projet JSON » pour récupérer les modifications en mémoire.

Mises à jour suivantes
Clique sur « Installer la mise à jour » dans le studio. INKFORGE vérifie une
copie de la version et de ses données avant de remplacer l’ancienne sauvegarde.
Ferme ensuite la fenêtre noire et relance ton lanceur habituel. Chaque nouvelle
version démarre avec un espace de travail vide. TripoSR reste installé.

Restaurer
Ouvre « Mises à jour » puis « Restaurer la version … ». La restauration remplace
le travail actuel. Si le studio ne démarre plus, ferme sa fenêtre noire et
double-clique sur RESTAURER_INKFORGE.cmd dans ton dossier INKFORGE.
Pour restaurer la 2.4.2, utilise le même navigateur et le même profil qu’avant.
La copie de secours vérifiée se trouve dans _secours_inkforge.zip.
